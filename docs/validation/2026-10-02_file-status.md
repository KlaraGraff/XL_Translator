# 文件运行状态修复与验证

日期：2026-10-02。范围：PDF/图片、Excel、Word 工作区与任务中心。依据：用户确认的文件状态方案及静态样张。

## 最终行为

- 文件统一显示“待处理 / 处理中 / 已生成”，处理阶段补充“提取文字 / 识别语言 / 翻译内容 / 生成文件 / 调整排版”。本地 PDF 恢复操作改用“待执行”“已安排”。
- 每个执行器在实际处理边界报告文件状态，界面不再从日志或阶段文字中的文件名猜测。PDF 的跨文件页面并行和 Excel/Word 的共享文本翻译保持原有调度方式。
- 已处理完页面但尚未合成 PDF 时显示等待生成；Excel 需要精调行高时等到该文件调整结束才显示已生成。
- 已生成结果保留“需复核”“整份未翻译”等提示。停止、失败、应用中断不会把剩余文件统一标成完成，也不会覆盖已生成文件。
- 暂停时，尚未执行的文件显示等待继续；已经提交且尚未返回的页面仍显示处理中，并注明等待已提交页面完成。
- 扫描、实时事件、状态快照、最终结果使用同一个文件 ID，支持不同目录下同名文件。快照与事件按逐文件版本号合并，重连及重新接管恢复当前状态。
- 工作区和任务中心共用状态文案。任务还在运行时，已生成文件在任务中心也可显示输出链接。旧任务历史继续使用原有结果展示，没有 schema 升版。
