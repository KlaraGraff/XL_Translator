# 界面文字放不下时怎么排

英文、法文比中文长得多：按界面词表实测，法文占的宽度中位数是中文的 2.1 倍、英文 1.7 倍；4 个字以内的按钮和标签，每 10 条里就有 1 条法文要 3 倍以上的宽度。按中文量好的按钮、卡片、右栏，换成英法文必然有地方放不下。

本软件的界面按下面三条规则排（2026-10-31 maple 确认，调研见方案文档「界面多语言文字放不下：业界做法与本软件方案」）。翻译出来的文档（Excel / Word / PPT / PDF / CAD 的缩字、加高、折行、复核）是另一回事，不受这里约束。

## 三条规则

**1. 名称类一律写全。** 按钮、标签、标题、菜单、下拉选项、提示、报错都算名称。放不下时按这个顺序处理：

1. 给空间：去掉写死的宽度、高度，让它跟着文字变宽变高。
2. 折行：折成两行，按钮也可以折（分段按钮就是这样）。
3. 换排法：「名称 + 下拉」并排放不下就上下排（右栏的「翻译方式」）；卡片 4 列放不下就排成 2 列（设置里的用途卡）。
4. 极少数实在没地方的位置（侧栏搜索框、可输入框的提示文字）才用词表里约定的短说法，鼠标停上去显示全称。短说法是文案改动，先给 maple 过目。

**2. 内容类可以截断，但要能看全文。** 文件名、路径、任务名、模型名、连接名这些用户自己的内容，单行放不下可以用「…」截断，鼠标停上去显示全文。

**3. 界面不缩字号。** 同一页字号忽大忽小会像出错，界面的小字已经是 11–12.5px，再缩就看不清。缩字只用于文档排版。

## 代码里怎么做

| 要做的事 | 用什么 |
|---|---|
| 内容单行截断 + 悬停全文 | 元素加 `FIT_CLIP`（`ui/src/text-fit.ts`，即 `.fit-clip`）。鼠标停上去、真被截断时自动补上全文提示；元素自己写了 `title` 的不动。 |
| 名称放不下 | 不写 `white-space: nowrap` + `overflow: hidden`，让它折行；固定 `height` 改成 `min-height`。 |
| 可输入下拉框的选中项 | 已经由 `createDropdown` / `createLanguagePicker` 处理：框里平时显示一层会折行的文字（`.combo-face`），点进去打字时才露出单行输入框。 |
| 「名称 + 下拉」一行 | `.selrow` 已经会在放不下时让下拉换到下一行并占满宽度。 |
| 输入框提示文字放不下 | `fitPlaceholder(input, 全称, 短说法)`：放得下照写全称，放不下换短说法、全称进悬停提示。 |

全软件只有 `app.css` 的 `.fit-clip` 一处写 `text-overflow: ellipsis`，`tests/test_ui_text_fit_contract.py` 把关。

## 自动检查

`scripts/ui_text_fit_check.mjs` 在 PR 检查里跑（「UI text fit」一项）：自己起一份隔离的后端（临时数据目录、带长文件名的样例文件、本机假模型，见 `scripts/ui_text_fit_server.py`）和 Vite 开发页，用 Chromium 按中文、英文、法文 × 常用（1380×900）和最小（1080×700）窗口逐页查：

- 快速开始弹窗、各页空白状态（展开「高级」等折叠块，点遍设置子页和页签）；
- 配好模型以后：Word 加了文件、Excel 加了文件和翻译完成、「反馈此任务」弹窗、任务页、首页、反馈页、设置页、搜索面板、PDF 图文指引。

报红的情况：名称被截断或裁掉、文字伸出框外、可输入框的提示文字放不下、内容被截断却悬停看不到全文、右栏横向滚动、整页横向滚动。另外跑一遍「法文加长 30%」的假语言（开发页里 `localStorage["translator.pseudo-long"] = "1"`），给以后加德语这类更长的语言留余量，只出报告、不拦合并。

报告和出问题画面的截图在 PR 检查的 artifact「ui-text-fit-report」里。本机跑：

```bash
node scripts/ui_text_fit_check.mjs --out .runtime/self-tests/ui-text-fit/report
# 只看一种语言、一种窗口：--locales fr --sizes min；不跑加长 30%：--no-pseudo
```

需要 `.venv`（或 `PYTHON` 环境变量指向装好 requirements.txt 的 Python）、`ui/node_modules`、Playwright 和 Chromium。检查用的字体和 CI 一致：拉丁字母用 Inter（和 macOS 界面字体 SF 宽度接近），中文用文泉驿正黑，配置在 `scripts/ui_text_fit_fonts.conf`。
