## 一、新信息架构

```
侧栏（图标+文字，分组）
├─ 翻译
│  ├─ Excel 表格
│  ├─ Word 文档
│  └─ PDF 与图片
├─ 资源
│  ├─ 任务中心          ← 活动任务数徽标
│  └─ 记忆库
└─ 系统（贴底）

   └─ 帮助

顶栏（每页）：页标题 + 状态徽章 + 一行简介 ｜ 右侧仅两个：活动任务药丸 · 当前模型药丸
```

## 二、六个结构问题 → 解法

1. **配置散在五处** → 全部收进设置页五个子页；改设置只有一个去处。
2. **右栏过重** → 右栏只留每次任务会动的：语言、本任务开关、专业领域选择（下拉，编辑入口跳设置）、输出位置。其余迁入设置→翻译参数。
3. **重复入口** → 帮助/更新/主题从顶栏移除；侧栏、设置页各一份唯一入口。
4. **任务状态三处** → 顶栏保留一个活动任务药丸（点击进任务中心）；工作区内只显示本工作区当前任务；任务中心是全量视图与历史唯一去处。
5. **结果占住工作区** → 任务终态改为工作区顶部**完成横幅**（摘要句+打开输出目录+查看完整报告→任务中心详情+关闭），工作区立即可开下一任务；完整结果（快照/KPI/结果定位清单/产物）归任务中心任务详情页。
6. **三页同构不可见** → 三个工作区用同一版式模板；右栏「本类型特有」开关单独分组并标注；共通区块位置、顺序、命名完全一致。

## 四、样张覆盖的屏目

1. Excel 工作区 · 空态（未选来源，右栏禁用态）
2. Excel 工作区 · 已扫描待开始（含 .xls 风险标记）

5. Excel 工作区 · 完成横幅（需复核非零的一例）
6. 任务中心 · 列表 + 任务详情（结果定位清单）
7. 记忆库
8. 设置 · 模型服务
9. 设置 · 翻译参数
