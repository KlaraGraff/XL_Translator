## 中文

这一版继续修复用户反馈的问题，没有新增功能。

### 改进与修复

**PDF 自动识别：转不成 Word 的页先试原位替换**
有些文字页转成 Word 会出问题（页数暴增、版面错乱，或电脑上没装 Word），以前这些页直接改用整页图像翻译，图像模型有时会画错数字、漏掉条目。现在先在原页面上替换文字，替换不成功才改用整页图像翻译；图像翻译也用不了，或者选了「保留原样」，就保留原文。

**PDF 转 Word：列表不再挤成一行**
原文里一条条用「-」开头的列表，最长的几条以前会被并成一段，译文里几条连在一起。现在每条单独成段，分开翻译。

**单独一个两字母的词照常翻译**
10.5.2 里，单独成段或单独占一格的两字母词（比如德文「Ja」、「OK」「Up」）没有送去翻译。现在照常翻译。

**讲义里的公式、变量和代码不再被乱翻、标黄**（反馈 #28）
- 公式和变量（比如「xyz」「Ai」「yi」）被模型原样还回来时，会先请模型复查一遍，复查时还会带上前后几格原文，判断更准。复查认可，或者说不出哪里该翻，就原样保留，不再重译三轮，也不再涂成需要复核的黄色。复查明确指出没翻的，照旧重译。
- 整段都是代码字体的代码段（比如「class Stack:」），原样保留，不再被译成「类 栈:」。正文里夹着的代码名照常翻译。
- PDF 转 Word 时，∑ ∫ ℝ 这类数学符号不再变成别的字母。

这份讲义还有问题没解决：转成 Word 后页数仍比原文多几页，个别页的框和标题排版还在改进，个别变量格子仍可能被标黄。

## English

This release continues to fix problems reported by users; there are no new features.

### Improvements and fixes

**PDF Automatic mix: pages that cannot be converted to Word now try in-place replacement first**
Some text pages go wrong when converted to Word (the page count balloons, the layout breaks, or Word is not installed). Those pages used to go straight to full-page image translation, where the image model sometimes drew wrong numbers or left items out. Now the text is first replaced on the original page; only if that fails does the page use full-page image translation, and if that is unavailable too, or "Keep original" is selected, the original is kept.

**PDF to Word: lists no longer run together on one line**
In lists whose items start with "-", the longest items used to be merged into one paragraph, so several items ran together in the translation. Each item is now its own paragraph and translated separately.

**Single two-letter words are translated again**
In 10.5.2, two-letter words standing alone in a paragraph or a cell (such as German "Ja", "OK", "Up") were not sent for translation. They are translated as usual again.

**Formulas, variables and code in lecture notes are no longer mistranslated or highlighted yellow** (feedback #28)
- When the model returns a formula or variable unchanged (such as "xyz", "Ai", "yi"), the model is asked to check it, now together with the text of the neighbouring cells so it can judge better. If the check agrees, or cannot point to anything that needs translating, it is kept as is: no more three rounds of retranslation and no yellow review highlight. If the check says it was not translated, it is retranslated as before.
- Code blocks written entirely in a code font (such as "class Stack:") are kept as they are instead of being translated word by word. Code names inside ordinary text are still translated.
- When converting PDF to Word, math symbols such as ∑ ∫ ℝ no longer turn into other letters.

Some problems with these notes remain: after conversion to Word the document still has a few more pages than the original, the layout of some boxes and title bars is still being improved, and an occasional variable cell may still be highlighted yellow.
