## 中文

**这是预发布的测试版。** 软件内不会提示升级到这一版，需要时请在下面下载安装，原有设置和数据都会保留。

**修复：Windows 上一键安装组件失败**
部分 Windows 电脑以前装不上「PDF 处理组件」或「文字识别组件」：缺少系统运行库、开着用不了的系统代理，或用户名里有中文时都会失败。现在这几种情况都能装好并正常使用。

**PDF 原位替换：进度看得见，每页状态清楚**
以前原位替换时，进度条很快到 90% 后长时间不动。现在进度按真实完成量推进，每一页显示「原位替换中」或「等待原位替换」，运行日志写明每一步。

**PDF 原位替换可以译成其他语言**
以前原位替换只能把外文图纸译成中文。现在也能把中文图纸译成法文、英文等（阿拉伯文、泰文等少数文字除外）。译文放不下时先压窄、再缩小、最后换行，规则与 CAD 一致，可在 PDF「高级」里的「原位替换排版」调整。

**PDF 自动组合：大页面也能翻译**
页面先按内容分类：扫描页按扫描页处理，能放进 Word 的文字页转成 Word 翻译，图纸和大页面用原位替换，不再按尺寸跳过。「大幅面起点」设置随之去掉。

**修复：PDF 暂停后马上继续会漏翻**
刚暂停就点「继续」时，以前剩下的页不再翻译，现在会接着翻完。

**其他改进**
提示中写明是哪个页面发出的；失败原因不再带程序内部名称；任务标题不再显示「中文 → 中文」；运行日志不再记录模型回复的原文。

## English

**This is a pre-release test build.** The app will not offer this version as an update; download and install it below if you need it. Your settings and data are kept.

**Fix: one-click component install failed on Windows**
Some Windows PCs could not install the PDF or OCR component: a missing system runtime, a system proxy that does not work, or a Chinese user name made it fail. These cases now install and work.

**PDF in-place replacement: visible progress and clear per-page status**
During in-place replacement the progress bar used to reach 90% quickly and then stand still. Progress now follows the real work, each page shows "Replacing in place" or "Waiting for in-place replacement", and the run log records every step.

**PDF in-place replacement into other languages**
In-place replacement used to translate foreign drawings into Chinese only. It can now also translate Chinese drawings into French, English and more (except a few scripts such as Arabic and Thai). Translations that do not fit are narrowed, then shrunk, then wrapped, following the same rules as CAD; adjust them under "In-place layout" in PDF Advanced.

**PDF Automatic mix: large pages are translated too**
Pages are sorted by content first: scans are handled as scans, text pages that fit in Word go through Word, and drawings and large pages are replaced in place instead of being skipped by size. The "Large-format threshold" setting is gone.

**Fix: resuming a PDF right after pausing skipped pages**
Clicking Resume just after a pause used to leave the remaining pages untranslated; they are now translated.

**Other improvements**
Notices name the page that sent them; failure reasons no longer carry internal names; the task header no longer reads "Chinese → Chinese"; the run log no longer records the model's raw reply.
