## 中文

**新增 CAD 图纸翻译**
支持 DWG 和 DXF 图纸，可暂停、停止和续译；DWG 需先在「插件」页配置 ODA File Converter。译文可单独显示，也可与原文上下双语显示；图框、标题栏等可锁定不翻译；译文过长时自动缩小，避免压到相邻文字。

**新增反馈页面**
侧栏新增「反馈」页，可快速描述问题、粘贴截图，并按需附带日志和文件。留下邮箱的，问题解决后会收到邮件回复。

**英语和法语界面**
新增对英语和法语的支持，可在「设置 → 外观与语言」中切换，即时生效。

**配色方案**
新增五套配色方案，浅色和深色模式可分别选择。

**翻译前先通读文档**
新增「自动识别场景」开关，默认开启：翻译前先通读文档，按文档的专业理解单独出现的短词，例如图纸门号里的「甲」不再译成合同中的「甲方」。

**提示词设置**
提示词改为固定的内置规则加可选的「补充要求」。原有三个场景预设已删除，自己写过的提示词升级后保留为补充要求。

**停止与续译**
Excel 任务停止时保存已完成的译文，再次开始可从中断处继续。

**出错处理**
API 密钥无效或额度用尽时，任务停止并显示原因；服务临时出错或超时会自动重试，重试次数可在设置中调整。

**翻译质量**
标准编号（如 GB/T 700-2006）不再送去翻译，已是目标语言的内容保持不变。

**速度与进度**
自动识别源语言时，Excel 改为并发翻译，速度明显提升；进度条按实际处理时间分配，后期不再长时间停滞。

**其他改进**
界面用语统一；PDF 进度显示更平稳；Windows 上关闭应用时任务正常结束；「导出诊断」恢复可用；自定义输出路径可点「浏览」选择。

## English

**New: CAD drawing translation**
DWG and DXF drawings can be translated, with pause, stop and resume. DWG files require ODA File Converter, configured on the Plugins page. Translations can be shown alone or above or below the source text; title blocks and frames can be excluded from translation; long translations are shrunk automatically so they do not overlap neighboring text.

**New: Feedback page**
A new Feedback page in the sidebar lets you quickly describe a problem, paste screenshots, and attach logs and files as needed. If you leave an email address, you will receive a reply when the issue is resolved.

**English and French interface**
The interface is now available in English and French, switchable under Settings > Appearance & language and applied immediately.

**Color schemes**
Five new color schemes are available, and light and dark mode can each use a different one.

**Reading the document before translating**
A new Auto-detect switch, on by default, reads the document before translation and interprets short standalone words by its field. For example, 甲 in a drawing's door number is no longer translated as "Party A" as in a contract.

**Prompt settings**
Prompts now consist of fixed built-in rules plus optional Extra instructions. The three former scene presets have been removed; prompts you wrote yourself are kept as extra instructions after the upgrade.

**Stop and resume**
When an Excel task is stopped, completed translations are saved, and the next run resumes from where it stopped.

**Error handling**
If the API key is rejected or the quota is exhausted, the task stops and shows the reason. Temporary service errors and timeouts are retried automatically, and the number of retries can be set in Settings.

**Translation quality**
Standard codes such as GB/T 700-2006 are no longer sent for translation, and text already in the target language is left unchanged.

**Speed and progress**
With automatic source-language detection, Excel now translates concurrently and is noticeably faster. Progress bars follow actual processing time and no longer stall near the end.

**Other improvements**
Consistent terminology across the interface; smoother PDF progress; running tasks end properly when the app is closed on Windows; Export diagnostics works again; a custom output folder can be chosen with Browse.
