## 中文

**新增 CAD 图纸翻译**
支持翻译 DWG 和 DXF 图纸，操作流程与 Excel、Word、PDF 一致，可暂停、停止和续译。DWG 文件需先在新增的「插件」页配置 ODA File Converter；支持 GBK 等中文编码的图纸，旧版 CAD 以特殊编码保存的中文也能正确识别。DWG 的格式转换在任务中进行，运行日志会逐张显示转换进度和用时；DWG 不多时，扫描后会自动逐张统计文字数，较多时可点「全部统计」，统计时转换好的图纸在翻译时直接使用。

**CAD 译文写回选项**
CAD 页新增「译文写回」设置。显示方式可选仅译文、原文在上译文在下、译文在上原文在下，双语时译文与原文在同一图层。「锁定不翻译」可指定图框、标题栏等图块和图层，其中的文字保持原样。译文较长、会压到相邻文字时，先收窄字宽，再缩小字号（默认先缩到 70%，最小 40%），仍放不下的列入报告供复核。译文默认用 AutoCAD 自带字体写入，在其他电脑上打开也能正常显示。

**新增英语和法语界面**
新增对英语和法语界面的支持，可在「设置 → 外观与语言」中切换。切换即时生效，停留在当前页面；各页面、运行日志、提示和错误信息均以所选语言显示；输出文件夹名称、报告文件及写入文档的复核标记仍为中文。

**配色方案**
「设置 → 外观与语言」新增五套配色方案：素雅灰、暖调纸感、冷调柔光、青瓷和琥珀护眼，浅色和深色模式可以分别选择。

**界面用语统一**
各功能名称在界面、日志、错误提示和报告中保持一致，不再显示程序内部术语。帮助与快速开始新增 CAD 说明。「深度清洗」更名为「清洗记忆库」，执行前会提示将产生模型调用费用。

**停止与续译**
Excel 任务停止时会保存已完成的译文，并将文件标记为「部分翻译」；再次开始时可从中断处继续。手动停止不再记为接口错误，也不再产生额外的模型调用；修正了翻译完成后重新扫描误报「源文件已变化」的问题。

**API 密钥与限流处理**
API 密钥无效或额度用尽时，任务会停止并显示原因。服务暂时出错或超时时，会自动重发该批内容，仍失败时改用备用连接；Excel 和 CAD 的重发次数可在「设置 → 翻译参数」中调整，默认 2 次；持续限流时，已完成的部分会先行保存，其余内容可稍后继续。

**模型服务设置**
切换模型后保留已设置的同时请求数，各连接独立保存速率设置，保存后页面信息即时更新；切换连接方式后立即保存，无需再点「保存配置」。修正了调整顺序或删除连接后误报「尚未填写 API 密钥」的问题。

**翻译前先通读文档**
各翻译页面新增「自动识别场景」开关，默认开启：翻译前先通读一遍文档，了解文档类型和所属专业，再据此理解单独出现的短词。例如图纸门号里的「甲」不再被译成合同中的「甲方」。开启后每份文件会多调用一次模型。

**提示词设置**
提示词改为固定的内置规则加可选的「补充要求」：内置规则每次都会发送，补充要求只追加在其后，不会替换内置规则。原有的同步工程、资料管理、行政生活化三个场景预设已删除。升级时旧设置自动迁移，自己写过或改过的提示词保留为补充要求，涉及内容转换时会先备份原设置文件。

**翻译质量**
GB/T 700-2006 等标准编号不再送去翻译。自动识别源语言时，已是目标语言的内容保持不变。Word 不再插入非目标语言的译文，并会提示文本框和脚注中未翻译的内容。

**性能与进度显示**
源语言为「自动识别」时，Excel 改为并发发送翻译请求，速度显著提升。Excel、Word 和 CAD 的进度条按模型处理时间分配，翻译后期不再长时间停滞。

**PDF 翻译**
进度显示更加平稳，页面不再跳回顶部，页面列表实时更新。未启用逐页审核时，不再显示「通过」状态。

**Windows 退出处理**
在 Windows 上关闭应用或安装更新时，正在运行的任务会正常结束，任务记录不再停留在「运行中」。

**导出诊断**
任务中心的「导出诊断」恢复可用。每个任务结束后会保留一份匿名诊断记录，仅包含任务类型、阶段、计数和服务商类别，不含文件名、路径、文档内容或密钥；升级前的任务没有诊断记录。

**应用内反馈**
侧栏新增「反馈」页，可描述问题或建议、粘贴截图，并按需附带系统与版本信息、所选任务的日志、原文件和译文（原文件和译文默认不附带）。发送前可查看将发送的全部内容，发送时显示上传进度，也可保存为 ZIP 文件。留下邮箱的，问题解决或功能上线后会收到邮件回复。日志已去除 API 密钥和文件路径，随反馈上传的文件保存 90 天后自动删除。

**其他界面改进**
提示消息移至页面顶部；窄窗口下表格布局保持正常；未配置模型时点击开始会引导至设置页；从「任务运行中」进入任务中心时自动选中当前任务；自定义输出路径可点「浏览」选择文件夹。

## English

**New: CAD drawing translation**
DWG and DXF drawings can now be translated, with the same workflow as Excel, Word and PDF, including pause, stop and resume. DWG files require ODA File Converter to be configured on the new Plugins page. Drawings in GBK and other Chinese encodings are supported, including Chinese text saved in the special encoding used by older CAD software. DWG conversion now runs as part of the task, and the run log shows the progress and time for each drawing. With only a few DWG files, their text is counted automatically after the scan; with more, use Count all. Drawings converted for counting are reused when translation starts.

**CAD output options**
The CAD page has new options for writing translations. Display can be Translation only, Source above translation, or Translation above source; in bilingual mode the translation goes on the same layer as the source. Do not translate keeps the text in chosen blocks and layers, such as title blocks and frames, unchanged. When a longer translation would overlap neighboring text, it is first narrowed and then reduced in size (to 70% first, down to 40% at most); anything that still does not fit is listed in the report for review. Translations are written in AutoCAD's built-in fonts by default, so they display correctly on other computers.

**New: English and French interface**
The interface now supports English and French, selectable under Settings > Appearance & language. The change takes effect immediately and stays on the current page. Pages, the run log, notifications and error messages are shown in the selected language; output folder names, report files and review markers written into documents remain in Chinese.

**Color schemes**
Settings > Appearance & language now offers five color schemes: Neutral grey, Warm paper, Soft cool, Celadon and Amber comfort. Light and dark mode can each use a different one.

**Consistent terminology**
Feature names are now consistent across the interface, run log, error messages and reports, and internal technical terms are no longer shown. Help and Quick Start now cover CAD. "Deep clean" is renamed "Clean up memory" and now warns that it incurs model charges before running.

**Stop and resume**
When an Excel task is stopped, completed translations are saved and the file is marked as partially translated; the next run can resume from where it stopped. A manual stop is no longer recorded as an API error and no longer triggers extra model requests. Rescanning after a finished task no longer falsely reports that the source file has changed.

**API key and rate-limit handling**
If the API key is rejected or the quota is exhausted, the task stops and shows the reason. If the service briefly fails or times out, the batch is resent automatically and moves to a backup connection if it still fails. For Excel and CAD, the number of resends can be set under Settings > Translation options (default 2). Under sustained rate limiting, completed work is saved and the remainder can be continued later.

**Model service settings**
The concurrent request limit is kept when switching models, each connection keeps its own rate settings, and the page updates immediately after saving. Switching the connection mode is saved immediately, without clicking Save settings. Fixed a false "API key not entered" warning after reordering or deleting connections.

**Reading the document before translating**
Each translation page has a new Auto-detect switch, on by default. Before translation, the document is read once to identify its type and field, and short standalone words are interpreted accordingly. For example, 甲 in a drawing's door number is no longer translated as "Party A" as in a contract. With the switch on, each file uses one additional model request.

**Prompt settings**
Prompts now consist of fixed built-in rules plus optional Extra instructions. The built-in rules are always sent, and extra instructions are only appended after them, never replacing them. The three former scene presets (Engineering coordination, Document management, and Administration & daily life) have been removed. Existing settings are migrated automatically on upgrade: prompts you wrote or edited are kept as extra instructions, and the settings file is backed up first whenever content is converted.

**Translation quality**
Standard codes such as GB/T 700-2006 are no longer sent for translation. With automatic source-language detection, text already in the target language is left unchanged. Word no longer inserts translations in the wrong language, and untranslated text in text boxes and footnotes is reported.

**Performance and progress display**
With automatic source-language detection, Excel now sends translation requests concurrently, which is significantly faster. Progress bars for Excel, Word and CAD now reflect model processing time and no longer stall near the end of translation.

**PDF translation**
Progress is displayed more smoothly, the page no longer jumps back to the top, and the page list updates in real time. Pages are no longer marked as passed when page-by-page review is off.

**Shutdown on Windows**
Closing the app or installing an update on Windows now ends running tasks properly, and task history no longer remains at "running".

**Diagnostics export**
Export diagnostics in the task center works again. Each finished task now keeps an anonymous diagnostic record containing only the task type, stage, counts and provider category, without file names, paths, document content or keys. Tasks from before the upgrade have no record.

**In-app feedback**
A new Feedback page in the sidebar lets you describe a problem or suggestion, paste screenshots, and optionally attach system and version information, plus the log, source files and translations of selected tasks (source files and translations are not attached by default). You can review everything that will be sent beforehand and follow the upload progress while it is sent, or save it as a ZIP file instead. If you leave an email address, you will be notified by email when the issue is resolved or the feature is released. Logs have API keys and file paths removed, and uploaded files are deleted automatically after 90 days.

**Other interface improvements**
Notifications now appear at the top of the page; tables keep their layout in narrow windows; starting without a configured model opens the settings page; opening the task center from the "tasks running" indicator selects the current task; a custom output folder can be chosen with Browse.
