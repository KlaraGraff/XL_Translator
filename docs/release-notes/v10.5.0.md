## 中文

### 新功能

**字幕翻译**
新增「字幕」翻译类型，支持 .srt、.vtt、.ass 字幕文件。一句话分在几条字幕里时，会合起来翻译再分回各条，时间轴保持不变。

**繁体中文**
翻译目标语言和软件界面语言都可以选择繁体中文。

**记忆库导入兼容更多表格**
导入自己的词表时，会自动识别哪一列是原文、哪一列是译文，以及文件的编码和分隔符；格式略有差异也能正常导入，预览里可以手动改列，并提供导入模板。

**Word 未接受的修订**
扫描时会自动检查 Word 文件里还没有接受的修订。点击「开始翻译」时可以选择：先在 Word 里处理修订再翻译；修订一起翻译，并保留修订标记；跳过修订，只翻译其余部分（默认）。

**Word 内容控件里的文字也会翻译**
Word 表单里的内容控件文字以前不会翻译，现在会翻译。开启「保护封面和目录」时，封面页上的控件保持原样。

**记忆库固定词条**
记忆库新增「固定」一列：可以固定或取消固定（可撤销），可批量固定，可用「只看固定」筛选。修改或删除固定的词条前会先请您确认，批量删除时固定的词条会保留。

**阿里百炼「深度思考」开关**
使用阿里百炼模型时，可以选择跟随模型默认、不启用或启用深度思考。

**组件下载国内镜像**
扩展组件和文字识别语言数据增加国内更容易连上的下载节点，在国内下载更快。

### 改进与修复

**原文语言选「自动识别」时不再漏翻日文**
日文里只有汉字的格子、段落以前会漏翻，现在会翻；识别不出语言时会换更多句子再识别一次；中日写法相同的词（品名、数量）不再误报需复核。Word 多个文件一起翻译时，每个文件按自己的语言处理。

**图像翻译：先确认模型能识别图片**
以前审核模型不能识别图片时，也会照常发图，得到不可靠的结果。现在开始前会先确认模型能看到图片，不能时会提示您更换模型或本次不审核；任务中发现不行也会停止发图。额度或余额用完造成的失败，不会被记成「模型不可用」。

**未通过规则检查的译文改由模型复核**
以前没通过规则检查的译文会被直接丢掉，现在会交给模型再复核一次，检查结果更准确。

**PDF 转 Word：页数不再暴增**
个别 PDF 转成 Word 后页数大幅增加、排版错乱（例如 322 页变成 2581 页）。现在转坏的页不会再拼进译文。

**CAD 排版和漏翻**
上下排成一列的说明，译文整列往下排开，不再压到下一条上；引线上的长说明缩到最小仍放不下时折成两行，并避开视口里的墙线；布局上的视图标题不再漏翻；带下划线的标题不越过下划线。译文对照表里手填的译文都能写回。

**本机模型服务不再一次发出大量请求**
地址是本机的模型服务（例如 Ollama）现在按本地模型发送请求，不再一次同时发出 30 批，翻译不再卡住或报错。

**停止翻译立即生效**
以前遇到限速等待时，点「停止」要等重试结束。现在立即停止；服务器要求等待时最多等 30 秒。

**退出程序更干净**
关闭软件时会取消正在等待的模型请求，并结束引擎启动的外部程序，不再留在后台或拖住退出。

**模型兼容**
修复 Claude 深度思考类模型偶尔返回空白译文、Claude 3 系列被拒绝的问题；本机模型填错模型名时不再反复重试。

**繁体中文、粤语译文不再被还原**
目标语言为繁体中文或粤语、译文里引用英文合同术语时，以前会被当成没翻而还原为原文，现在不会了。

**Word 格式更完整**
带书签的文字、颜色或上标的短字段，翻译后格式不再错位或扩散到别处。「保护封面和目录」也对编号处理生效。

**Excel 公式**
关闭「公式显示值回填」时，公式会完整保留，不再被替换为固定文字。

**网址、邮箱和文件路径保持原样**
网址、邮箱地址和文件路径不再被送去翻译。

**测试连接不覆盖刚改的设置**
测试连接过程中修改的设置，以前会被测试结果覆盖，现在会保留。

**拖入多个文件夹的文件**
从几个文件夹同时拖入文件时，所有文件都会加入，不再只留下一部分。

**其他修复**
补译模式下，两行完全相同的格子或段落会被识别为未翻译；系统代理设成 SOCKS 时翻译、反馈和检查更新不再出错；模型速度设置第一次保存时不再丢掉一项；PDF「换回上一版」不会再删掉压缩后的 PDF；损坏、不完整的 .xls 文件会给出提示；界面文字过长时可以悬停查看全文；英文、法文的单复数显示正确；另有多项 PDF 报告和设置文件的稳定性改进。

## English

### New features

**Subtitle translation**
A new Subtitles translation type supports .srt, .vtt and .ass files. A sentence split across several subtitles is translated as a whole and then split back, with timings unchanged.

**Traditional Chinese**
Traditional Chinese can now be chosen both as a target language and as the interface language.

**Translation memory import accepts more spreadsheets**
When importing your own glossary, the source and target columns, the encoding and the delimiter are detected automatically, so slightly different layouts import correctly. Columns can be changed in the preview, and an import template is provided.

**Unaccepted tracked changes in Word**
Scanning now detects tracked changes that have not been accepted. When you click Start, you can choose to resolve the changes in Word first, translate the changes too while keeping the revision marks, or skip the changes and translate the rest (default).

**Text in Word content controls is translated**
Text inside Word content controls (form fields) used to be left untranslated; it is now translated. With "Skip cover and contents" on, controls on the cover page are left as they are.

**Locked translation memory entries**
The translation memory gains a Locked column: lock or unlock entries (with undo), lock in bulk, and filter with "Locked only". You are asked to confirm before editing or deleting a locked entry, and bulk delete keeps locked entries.

**Deep thinking switch for Alibaba Bailian**
With Alibaba Bailian models you can choose to follow the model default, turn deep thinking off, or turn it on.

**Download mirror for China**
Extension components and text recognition language data gain a download source that is easier to reach from China, so downloads there are faster.

### Improvements and fixes

**Japanese is no longer skipped with Auto-detect**
With the source language set to Auto-detect, Japanese cells and paragraphs written only in kanji used to be left untranslated; they are now translated. When the language cannot be identified, a larger set of sentences is checked once more, and words written the same way in Chinese and Japanese (such as 品名, 数量) are no longer flagged for review. In a multi-file Word batch, each file is handled in its own language.

**Image translation: checks that the model can read images first**
A review model that could not read images used to be sent page images anyway, giving unreliable results. The app now confirms before starting that the model can see images and, if not, offers to change the model or skip review this time; if the problem shows up during a task, it stops sending images. Failures caused by an exhausted quota or balance are no longer recorded as "model unavailable".

**Translations failing the rule check are reviewed by the model**
Translations that failed the rule check used to be discarded; they are now reviewed once more by the model, so the results are more accurate.

**PDF to Word: no more page count blow-ups**
Some PDFs converted to Word gained a huge number of pages with a broken layout (for example 322 pages becoming 2,581). Badly converted pages are no longer merged into the translation.

**CAD layout and missed text**
In a column of stacked notes, translations now push the whole column down instead of overlapping the next note; a long leader note that still does not fit at the smallest size wraps onto two lines and avoids wall lines in the viewport; view titles on layouts are no longer missed; underlined titles stay within the underline. Translations typed by hand in the translation table are all written back.

**Local model services no longer receive a flood of requests**
A model service at a local address (such as Ollama) is now treated as a local model, instead of receiving 30 batches at once, so translation no longer stalls or fails.

**Stop takes effect immediately**
Clicking Stop during a rate-limit wait used to wait for the retries to finish; it now stops at once. When the server asks to wait, the app waits at most 30 seconds.

**Cleaner exit**
Closing the app now cancels pending model requests and ends external programs started by the engine, so nothing is left running in the background or holds up the exit.

**Model compatibility**
Fixed Claude thinking models occasionally returning empty translations and Claude 3 models being rejected; a wrong model name for a local model is no longer retried repeatedly.

**Traditional Chinese and Cantonese translations are no longer reverted**
Translations into Traditional Chinese or Cantonese that quoted English contract terms used to be treated as untranslated and reverted to the original; this no longer happens.

**Better Word formatting**
Bookmarked text and short coloured or superscript runs no longer shift or spread their formatting after translation. "Skip cover and contents" now also applies to numbering.

**Excel formulas**
With "Fill in formula display values" turned off, formulas are kept intact and are no longer replaced with static text.

**Web addresses, emails and file paths stay unchanged**
Web addresses, email addresses and file paths are no longer sent for translation.

**Test connection keeps settings you just changed**
Settings changed while a connection test was running used to be overwritten by the test result; they are now kept.

**Dropping files from several folders**
Files dropped from several folders at once are all added, instead of only some of them.

**Other fixes**
In fill-in mode, cells or paragraphs whose two lines are identical are recognized as untranslated; translation, feedback and update checks work when the system proxy is SOCKS; model speed settings no longer lose an entry on the first save; PDF "Restore previous" no longer deletes the compressed PDF; damaged or incomplete .xls files are reported; long interface text can be hovered to read in full; English and French singular and plural forms are correct; plus several stability improvements to PDF reports and the settings file.
