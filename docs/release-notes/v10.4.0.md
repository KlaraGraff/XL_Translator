## 中文

**新增：PDF、CAD 翻译图文指引**
首次进入 PDF 页或 CAD 页时，会以图文说明各翻译方式的适用场景、效果和所需组件，之后可通过顶栏「使用说明」或帮助页再次查看。CAD 页的「输出：双语对照 / 仅译文」已从「高级」移至右栏上方。

**改进：输出位置无效时，译文不再丢失**
此前，输出位置无效或无法写入时，翻译文件可能无法保存。现在会自动改存到备用输出文件夹（可在「高级 → 输出位置」中设置，默认为桌面）。此外，译文也可选择直接放回源文件所在的文件夹，源文件不会被覆盖。

**改进：PDF「原位替换」放不下的译文默认照常写入**
此前，经压窄、缩小和换行后仍放不下的译文会保留原文。现在默认写入译文，也可改为「优先保持版式（保持原文）」；两种方式都会在结果中标出需要复核的位置。

**改进：一键安装「文字识别组件」**
此前需先手动安装「PDF 处理组件」，才能安装「文字识别组件」。现在缺少时，一键安装会自动先装好「PDF 处理组件」。

**修复：PDF 转成 Word 并仅输出译文时，部分内容仍为双语、页数增加**
此前，部分表格单元格仍同时显示原文和译文，页脚可能被挤到下一页，导致页数增加。现在这些单元格只显示译文，页脚保持在每页底部，页码写法统一。译文中偶尔混入其他语言文字、同一词组前后译法不一致的情况也已改善。

## English

**New: illustrated guides for PDF and CAD translation**
The first time the PDF or CAD page is opened, an illustrated guide explains what each translation method is suited to, what results to expect and which components it needs. It can be reopened from "How it works" in the top bar or from the Help page. On the CAD page, "Output: Bilingual / Translation only" has moved from Advanced to the top of the right panel.

**Improvement: translations are no longer lost when the output location is invalid**
Previously, if the output location was invalid or could not be written, the translated file might not be saved. It is now saved to a backup output folder instead (set under Advanced → Output location; the Desktop by default). Translations can also be placed directly beside the source files; source files are never overwritten.

**Improvement: PDF "Replace in place" now writes translations that do not fit**
Previously, a translation that still did not fit after narrowing, reducing and wrapping was left in the original language. The translation is now written by default; you can switch to "Preserve the layout (keep the original)" instead. Both options mark the locations that need review.

**Improvement: one-click install of the Text recognition component**
Previously, the PDF processing component had to be installed manually before the Text recognition component. One-click install now adds the PDF processing component automatically when it is missing.

**Fix: PDFs converted to Word with "Translation only" kept bilingual content and gained pages**
Previously, some table cells still showed both the original and the translation, and footers could be pushed onto the next page, increasing the page count. These cells now show only the translation, footers stay at the bottom of each page, and page numbers are written consistently. Stray words in other languages and inconsistent translations of the same phrase have also been reduced.
