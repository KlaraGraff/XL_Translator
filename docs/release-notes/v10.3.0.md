## 中文

**新增 PPT 翻译**
侧栏新增「PPT」，可翻译 .pptx、.pptm、.ppsx、.potx，旧版 .ppt、.pps 会先自动转换（输出为 .pptx）。幻灯片上的文本框、表格、演讲者备注、图表、SmartArt 和母版上的固定文字都会翻译，加粗、颜色和超链接按原文保留。译文较长放不下时，可选择加高文本框、保持字号或固定版面。

**界面全新设计**
新增「翻译」入口页，可把文件或文件夹拖到窗口任意位置，自动进入对应的翻译页。默认配色换成「流光」，原来使用默认配色的用户升级后会自动更换，原有配色仍可在设置中选择。侧栏精简为 7 项，插件、扩展和智能体接入合并为「扩展」页；任务、记忆库、设置、帮助和反馈页均重新排版，所有下拉框都可以直接输入筛选。

**Word、Excel 保留段内格式**
以前一段或一个单元格里只有部分文字加粗或变色时，译文会变成一种格式。现在加粗、颜色按原文对应的位置写回；Word 段落里的制表位、换行、图片和脚注编号也留在原来的位置。

**合同关键信息核对**
译文中的证件号、日期、人名与原文不一致时（如证件号中的字母被改、日期的日和月颠倒、人名拼写被改），会标记为需复核，并在复核清单中写明原文。适用于 Excel、Word 和 PPT。

**全局搜索**
Mac 按 ⌘K、Windows 按 Ctrl+K，可搜索页面、任务和记忆库词条；输入文件路径后按回车，即可开始翻译。

**混合文件夹一键全部开始**
拖入同时含表格、文档、PPT 等多种文件的文件夹后，「翻译」页会列出各类文件和各自的设置，点「全部开始」即可一起翻译，结果放在同一个输出文件夹中。

**其他改进**
翻译进行中的进度区、任务页的统计数字和任务列表不再闪烁，切换页面时不再留下残影；各翻译页路径栏右侧的按钮改为「选择」；「12 万」等带「万」「亿」的数字正确换算后不再被退回原文；系统代理失效时，发送反馈和检查更新会自动直连重试；各翻译页的「高级」设置第一次进入时展开；CAD 任务记录新增「保留原文」一项，与页面上的「待翻译」数目对得上；读取文件夹时跳过 Office 的临时锁文件；另有多项细节改进与问题修复。

## English

**New: PowerPoint translation**
A new PowerPoint entry in the sidebar translates .pptx, .pptm, .ppsx and .potx files; older .ppt and .pps files are converted automatically first (output is .pptx). Text boxes, tables, speaker notes, charts, SmartArt and fixed text on slide masters are all translated, keeping bold, colors and hyperlinks as in the original. When a translation is too long to fit, you can choose to enlarge the text box, keep the font size or keep the layout fixed.

**A redesigned interface**
A new Translation start page lets you drop files or folders anywhere in the window and takes you to the right translation page. The default palette is now Lumen; users on the old default switch to it on upgrade, and the earlier palettes remain available in Settings. The sidebar now has 7 items, with plugins, extensions and agent access combined into one Extensions page; the Tasks, Translation memory, Settings, Help and Feedback pages have new layouts, and every dropdown accepts typing to filter.

**Word and Excel keep formatting within a paragraph**
When only part of a paragraph or cell was bold or colored, the translation used to come out in a single format. Bold and colors are now written back in the matching places, and tab stops, line breaks, pictures and footnote numbers in Word paragraphs stay where they were.

**Key details in contracts are checked**
When an ID number, date or name in the translation differs from the source (for example a changed letter in an ID number, day and month swapped, or a misspelt name), it is marked for review, with the original shown in the review list. This applies to Excel, Word and PowerPoint.

**Global search**
Press ⌘K on Mac or Ctrl+K on Windows to search pages, tasks and translation memory entries; type a file path and press Enter to start translating it.

**Start a mixed folder in one click**
After dropping a folder that holds spreadsheets, documents, presentations and other files together, the Translation page lists each kind of file with its settings; click Start all to translate them together, with the results in one output folder.

**Other improvements**
The progress area during translation, the figures and list on the Tasks page no longer flicker, and switching pages no longer leaves a trace of the previous page; the button on the right of each translation page's path bar now reads Select; numbers with 万 or 亿 converted correctly are no longer reverted to the source; feedback and update checks retry without the proxy when the system proxy no longer works; the Advanced options on each translation page are open the first time; CAD task records now show a "Kept as is" count that matches "To translate" on the page; Office lock files are skipped when reading folders; plus various other refinements and fixes.
