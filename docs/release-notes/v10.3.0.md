## 中文

**较长的文档，用词前后一致**
翻译前先为文档中反复出现的词定好译法，各部分统一采用，不再出现同一个词前后译法不同的情况。开启「自动识别场景」（默认开启）且文档约 3000 字以上时生效，适用于 Excel、Word（含 PDF 转 Word）和 CAD。

**CAD：译文排版更整齐**
译文较长时会自动缩小，不再伸出图框、越出表格格子，也不再压到旁边的文字、门的开启线和箭头；窄格子里放不下的译文折成两行；同一列说明的译文字高保持一致。

**新增「扩展」页，可翻译更多文件类型**
可在「扩展」页选择侧栏显示哪些翻译类型并调整顺序。新增「文本」类型，可翻译 .txt 和 Markdown 文件，在「扩展」页开启后使用。也可以从扩展列表或本地文件添加扩展，以支持更多文件类型。

**可由智能体调用 Translator**
侧栏新增「MCP」页，一键复制接入说明，发给 Claude 等智能体后，智能体即可调用 Translator 翻译文件，任务同样显示在任务中心。

**速率与重试按文件类型设置**
同时请求数、每批条数、重试次数等设置从「模型服务」移到「设置 → 翻译参数」，Excel、Word、PDF、CAD 可分别设置。升级后这几项改用新的默认值；如之前调整过，请在新位置重新设置。

**更换模型服务后可正常保存**
文档翻译换成 DeepSeek、阿里百炼或本地模型时，设置可以正常保存。某项用途因此无法使用时，「模型服务」页会标出并说明原因。

**其他改进**
PDF 原位替换中未取得译文的文字会标记为需复核；CAD 任务的状态显示与文件状态保持一致；「?」说明框不再闪烁或错位；另有多项细节改进与问题修复。

## English

**Consistent wording in longer documents**
Before translating, a translation is fixed for each term that recurs in the document and used throughout, so the same term is no longer translated differently in different places. This applies when Auto-detect is on (the default) and the document has roughly 3,000 characters or more, in Excel, Word (including PDF to Word) and CAD.

**CAD: tidier layout of translations**
Long translations are shrunk automatically so they no longer extend past the drawing frame or out of table cells, or overlap nearby text, door swings and arrows; translations that do not fit in a narrow cell wrap onto two lines; translations in the same column of notes keep the same text height.

**New Extensions page for more file types**
On the Extensions page you can choose which translation types appear in the sidebar and change their order. A new Text type translates .txt and Markdown files once turned on there. You can also add extensions from the extension list or from a local file to support more file types.

**Let AI agents use Translator**
A new MCP page in the sidebar copies setup instructions in one click; give them to Claude or another AI agent and it can use Translator to translate files, with tasks shown in the task center as usual.

**Rate and retry settings per file type**
Settings such as concurrent requests, items per batch and retry counts have moved from Models to Settings → Translation options, and can be set separately for Excel, Word, PDF and CAD. After upgrading these use new default values; if you had changed them, set them again in the new place.

**Settings save correctly after switching model service**
Document translation settings now save correctly after switching to DeepSeek, Alibaba Bailian or a local model. If another use can no longer work as a result, the Models page marks it and explains why.

**Other improvements**
In PDF in-place replacement, text that could not be translated is marked for review; CAD task status now matches file status; "?" help pop-ups no longer flicker or jump; plus various other refinements and fixes.
