## 中文

**修复：PDF 翻译选硅基流动时无法使用**
以前在「PDF 与图片翻译」中选硅基流动，任何模型都连接不上。现在可以正常连接，审核也按连接设置发送请求；硅基流动默认改用国内站地址。图像翻译填成文字模型时，会提示需使用图像模型，并可一键改为转成 Word 翻译。

**模型服务设置更清楚**
选择服务商时不再预填型号，请获取模型列表后自行选择。「OpenAI 兼容」改名为「自定义配置」，「Claude」改名为「Anthropic」；选中服务商后，点「获取 ↗ API 密钥」即可打开它的密钥页面。

**修复：Excel 部分行的行高不对**
合并的标题行、中文表头和较长的标题，译文不再被裁掉一截，也不会把整行撑得过高。

**其他改进**
混合文件夹翻译时，「本批文件」卡片不再闪烁，各行对齐；「翻译」页拖放区的说明补上 PPT，.pptx 排在扩展名第一位；反馈页的任务状态与任务页一致；设置中分段按钮的滑块对齐。

## English

**Fix: SiliconFlow could not be used for PDF translation**
Choosing SiliconFlow for PDF and image translation used to fail with every model. It now connects, and review follows the connection settings too; SiliconFlow now defaults to its China endpoint. When a text model is entered where an image model is needed, a message says so and offers one click to switch to Convert to Word.

**Clearer model service settings**
Picking a provider no longer fills in a model; fetch the model list and choose one. "OpenAI-compatible" is now "Custom configuration" and "Claude" is now "Anthropic". With a provider selected, click "Get ↗ API key" to open its key page.

**Fix: wrong row heights on some Excel rows**
Merged title rows, Chinese headers and long titles are no longer cut off, and no longer make the whole row too tall.

**Other improvements**
The "This batch" card no longer flickers during a mixed-folder run, and its rows line up; the Translate page's drop area now mentions PowerPoint, with .pptx listed first; task status on the feedback page matches the Tasks page; segmented control thumbs in Settings line up.
