## 中文

这一版集中修复了用户反馈的问题，没有新增功能。

### 改进与修复

**用 DeepSeek 翻译时不再一条都翻不出来**
装过「文字识别组件」之后，用 DeepSeek 翻译有时整份文件一句都没翻，输出的还是原文。原因是软件解不开 DeepSeek 发回来的压缩回答。现在已经改好，DeepSeek 照常翻译。

**翻译请求全部失败时，任务会显示「失败」**
以前模型一条译文都没返回（例如密钥失效、服务出故障）时，任务仍然显示「完成」或「已生成」，交出来的文件全是原文。现在 Excel、Word、PDF、PPT 和 CAD 图纸遇到这种情况都会显示失败，并写明失败原因；只是部分内容没翻成时照旧交出文件并标出来。

**Windows 上文件名以点结尾的 PDF 不再报「文件不存在」**（反馈 #32）
像「项目说明....pdf」这种去掉扩展名后以点结尾的文件，在 Windows 上翻译会报「文件不存在」。现在可以正常翻译。

**长 PDF 转 Word 不再整段放弃**（反馈 #30）
很长的 PDF 转成 Word 时，只要中间夹着空白页，或者其中几页译文排得太长，以前会把一大段几十页整段退回不用。现在只退回真正有问题的那几页，其余照常放进译文。

**需要「PDF 处理组件」时，开始前就提醒**（反馈 #33）
翻译 A3 图纸这类大幅面 PDF 时，如果本机没装「PDF 处理组件」，以前要等全部跑完才失败。现在点开始时先弹窗说明有几页会保留原样、几页改用整页图像翻译，可以先去安装组件，也可以仍然开始；点取消后开始按钮照常可用。

**PDF 自动识别：空白页不再被说成「大幅面」**
空白页会原样放进译文，但以前日志和逐页结果里把它写成「大幅面页」。现在写的是「空白页」，大幅面页数也不再算它。

**PDF 转 Word：讲义里的彩色框、数学符号和公式**（反馈 #28）
- 「Note / Example / Exercise」这类彩色框，正文格子不再被涂成深色盖住文字，标题格子也不再白字白底，底色按原页面的颜色来。
- ∨ ⊆ ∅ 这类数学符号换成 Office 自带的字体，Mac 上的 Word 不再显示成方框；2^k 这类上下标按原文保留。
- 不再无故多出页：没有要翻的表格（比如真值表）保持原来的行高，以前一份 104 页的讲义会多出十几页。
- 只有变量、数字、符号的公式行和编号（如「(A1 ∧ A2) ⇒ C」「(ii)」「is_empty(S)」）不再送去翻译，也不再被标成需要复核的黄色；公式里夹着的英文单词照常翻译。

**PDF 原位替换：浅灰色文字、接线图和屏幕示意框**
- 浅灰色的正文以前会被误判成「中文显示不出来」而放弃，现在能正常处理。
- 接线图、封底这类页面，以前写完译文后自检过于严格，页面看起来一点没变也会整页退回原文。现在只有页面真的被改坏了才退回。
- 屏幕示意框里的按键名（如「Press」「Manual」）不再和旁边的正文拼成一句乱翻，被框线穿过的按键名也能换成译文了。
- 图例里颜色圆点旁的文字、箭头两边的词，不再被并成一条或写到圆点、箭头上；一条译文不再挤占旁边另一条原文的位置，不会被挤成很小的字。

**整页图像翻译更稳**
- gpt-image-2 之后的新版本（2.5、2.6 系列）也按原页比例出图，不再四周补一圈白边。
- 模型把页面内容画小了会自动重做一次，仍然偏小就交出这张图并提示换模型；比例完全不对的图不再硬拉伸，而是标出来不采用。
- 推荐模型改为 gpt-image-2.6-sunburst，其次是 gpt-image-2.6-flare。PDF 本身带文字时，选「自动识别」转成 Word 结果最稳。

**Word 双语翻译：带项目符号的段落不再变成符号**
带项目符号的段落，译文以前可能沿用符号字体，普通文字显示成一串符号。现在译文用正常字体。

## English

This release focuses on fixing problems reported by users; there are no new features.

### Improvements and fixes

**DeepSeek translations no longer come back empty**
After the Text recognition component was installed, translating with DeepSeek sometimes left a whole file untranslated, because the app could not unpack DeepSeek's compressed answers. This is fixed and DeepSeek translates normally again.

**A task whose translation requests all fail now shows "Failed"**
When the model returned no translation at all (for example, an invalid key or a service outage), the task used to show "Done" or "Generated" and deliver a file still in the original language. Excel, Word, PDF, PowerPoint and CAD drawings now show the task as failed and say why; when only part of the content fails, the file is still delivered with those parts marked.

**PDFs whose names end with a dot no longer report "file not found" on Windows** (feedback #32)
A file such as "Project notes....pdf", whose name ends with a dot once the extension is removed, used to fail with "file not found" on Windows. It now translates normally.

**Long PDFs converted to Word no longer drop whole sections** (feedback #30)
When converting a long PDF to Word, a blank page in the middle, or a few pages whose translation ran too long, used to make a whole section of dozens of pages be thrown away. Now only the pages that actually have a problem are sent back, and the rest go into the translation as usual.

**A warning before starting when the PDF processing component is needed** (feedback #33)
When translating large-format PDFs such as A3 drawings without the PDF processing component installed, the task used to fail only after running to the end. Clicking Start now shows how many pages would be kept as they are and how many would use full-page image translation, so you can install the component first or start anyway; after Cancel, the Start button works as usual.

**PDF Automatic mix: blank pages are no longer called "large format"**
Blank pages are placed into the translation unchanged, but the log and page results used to call them large-format pages. They are now shown as blank pages and no longer counted as large format.

**PDF to Word: colored boxes, math symbols and formulas in lecture notes** (feedback #28)
- In colored boxes such as "Note / Example / Exercise", body cells are no longer painted dark over the text and title cells no longer show white text on white; the background follows the original page.
- Math symbols such as ∨ ⊆ ∅ now use a font that ships with Office, so Word on Mac no longer shows empty boxes; superscripts and subscripts such as 2^k are kept as in the original.
- No more extra pages: tables with nothing to translate (such as truth tables) keep their original row height; a 104-page set of notes used to grow by more than a dozen pages.
- Formula lines and labels made only of variables, numbers and symbols (such as "(A1 ∧ A2) ⇒ C", "(ii)", "is_empty(S)") are no longer sent for translation or highlighted yellow for review; English words inside a formula are still translated.

**PDF in-place replacement: light grey text, wiring diagrams and screen mock-ups**
- Light grey body text used to be mistaken for "Chinese cannot be displayed" and given up on; it is now handled normally.
- On pages such as wiring diagrams and back covers, the self-check after writing the translation was too strict and sent the whole page back to the original even when nothing visible had changed. A page is now sent back only when it was actually damaged.
- Button labels in screen mock-ups (such as "Press" and "Manual") are no longer joined to the nearby body text into one garbled sentence, and labels crossed by a frame line can now be replaced too.
- Text next to color dots in a legend and words on either side of an arrow are no longer merged into one entry or written over the dot or arrow; one translation no longer takes the space of another, so none gets squeezed into tiny text.

**Steadier full-page image translation**
- Versions after gpt-image-2 (the 2.5 and 2.6 series) now produce images in the original page proportions, without a white border added around them.
- When the model draws the page content too small, the page is redone once; if it is still too small, the image is delivered with a suggestion to switch models. An image with completely wrong proportions is no longer stretched to fit but marked as not used.
- The recommended model is now gpt-image-2.6-sunburst, followed by gpt-image-2.6-flare. For PDFs that contain real text, Automatic mix with conversion to Word gives the most reliable result.

**Word bilingual translation: bulleted paragraphs no longer turn into symbols**
For bulleted paragraphs, the translation could inherit the bullet's symbol font, so ordinary text showed up as a row of symbols. The translation now uses a normal font.
