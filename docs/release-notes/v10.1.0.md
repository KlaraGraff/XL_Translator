## 中文

**PDF：新增「自动组合」翻译方式（Beta）**
适合内容混杂的 PDF，例如同一份文件里既有扫描件、正文，又有图纸。每一页按类型选用合适的翻译方式，最后合成一份 PDF；图纸页只替换文字，线条和尺寸保持原样（目前只支持译成中文）。所需的「PDF 处理组件」和「文字识别组件」可在「插件」页一键安装，也可以通过「选择安装位置」使用已装好的组件。

**记忆库：译法更贴合场合，前后更一致**
同一个词在不同场合可以有不同译法：给词条加上备注写明适用场合，就只在相符的文档中采用，不会被误用到别处。词条出现在句子中间时，也按您设定的译法翻译，整份文档的用词更加一致。适用于 Excel、Word、PDF 和 CAD，整页图像翻译除外。

**CAD：可以直接修改译文**
翻译完成后，可在任务中心查看和修改译文，改完直接写回图纸，无需重新翻译。图纸中的表格现在也会翻译。

**Word 和 Excel：翻译更完整**
Word 的文本框、脚注，Excel 的文本框、形状和批注现在也会翻译；Word 译文保留加粗、斜体、链接等格式。

**安装包更小**
macOS 安装包从约 50 MB 减小到约 31 MB，Windows 安装程序从约 32 MB 减小到约 29 MB，功能不变。

**使用更方便**
任务中心可以搜索任务；在任务详情中可直接反馈该任务遇到的问题。

**其他改进**
使用响应较慢的模型服务时，Excel 不再因等待超时而漏译；另有翻译质量和排版方面的多项改进与问题修复。

## English

**PDF: new Automatic mix translation method (Beta)**
Suited to mixed PDFs, for example a file that contains scanned pages, body text and drawings. Each page is translated with a method suited to its type, and the result is assembled into one PDF; on drawing pages only the text is replaced, and lines and dimensions stay as they are (currently into Chinese only). The PDF processing component and the text recognition component it uses can be installed with one click on the Plugins page, or you can point to components you already have with Choose location.

**Translation memory: translations that fit the context and stay consistent**
The same term can have different translations in different contexts: add a note to an entry describing where it applies, and it is used only in matching documents instead of being applied elsewhere by mistake. When a term appears in the middle of a sentence, your translation is used there too, so wording stays consistent across the document. This applies to Excel, Word, PDF and CAD, except full-page image translation.

**CAD: edit translations directly**
After translation, you can review and edit the translations in the task center and write them back into the drawings without translating again. Tables in drawings are now translated as well.

**Word and Excel: more complete translation**
Text boxes and footnotes in Word, and text boxes, shapes and comments in Excel, are now translated; Word translations keep bold, italics, links and similar formatting.

**Smaller installers**
The macOS installer is down from about 50 MB to about 31 MB, and the Windows installer from about 32 MB to about 29 MB, with no change in features.

**Easier to use**
The task center can now be searched, and you can send feedback about a task directly from its details.

**Other improvements**
With slow model services, Excel no longer leaves text untranslated because a request ran out of time; plus various improvements and fixes to translation quality and layout.
