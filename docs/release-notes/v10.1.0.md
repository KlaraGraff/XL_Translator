## 中文

**记忆库：设定的译法在句中同样采用**
在记忆库中手动维护的译法，出现在长句中时也会采用；未采用时自动重新翻译，仍未采用的位置在输出文件中标记需复核，重试次数可在设置中调整。词条可填写备注，填写后仅在备注所述场景中采用。记忆库页面默认只显示常用内容，更多选项在「高级模式」中。目前适用于 Excel 和 Word。

**PDF 新增翻译方式「自动组合」（Beta）**
默认仍为整页图像翻译。选择「自动组合」后按页面类型分别处理：扫描页按图像翻译；可提取文字的页转成 Word 翻译后再转回 PDF；图纸页直接在原 PDF 上替换文字，线条和尺寸保持不变（目前只支持译成中文）。某页无法使用所选方式时改用设定的保底方式，最后按原页序合成一份 PDF。转成 Word 需在「插件」页连接「PDF 转 Word 组件」。

**CAD：查看与修改译文**
任务完成后，可在任务中心打开译文对照表，直接修改译文，或导出为 Excel 修改后再导入，然后按修改写回图纸，不再调用模型。

**CAD 其他改进**
AutoCAD 表格中的文字现在也会翻译，格子放不下时译文自动缩小。新增「输出图纸版本」，默认与原图相同，AutoCAD 2017 及更早的版本也能打开。译成中文时默认保持原字号，放不下时再自动缩小。双语模式下，编号、规格等译前译后相同的文字不再重复一行。

**Word：文本框、脚注和段内格式**
文本框和脚注、尾注中的文字现在会翻译；段内的加粗、斜体、链接、上标等局部格式在译文中保留。从 PDF 复制来的段落中，句中换行先合并再翻译；表格行随译文自动变高，不再裁掉文字；译成中文、日文、韩文时，标点不再出现在行首。

**Excel：文本框、形状和批注**
文本框和形状中的文字现在会翻译，译文放不下时自动缩小字号。批注可选择翻译，开关为「翻译批注」，默认关闭。

**提示词设置**
「自动识别场景」开关统一放在「设置 → 翻译参数 → 提示词设置」中，各翻译页不再单独显示。标题旁的「?」可查看每次发送给模型的内容由哪几部分组成。

**任务中心与反馈**
任务中心新增搜索框，可按文件名、类型和状态查找。任务详情和翻译结果中新增「反馈此任务」，可直接附上该任务的日志和文件。反馈页记住上次填写的邮箱，截图不再限制张数。任务过程文件的保留上限可在「设置 → 数据与维护」中调整。

**翻译质量**
日期译成月份名（如「12 octobre 2026」）时不再被误判而退回原文；原文中的提问或指令只翻译，不再被当作要求执行；拉丁字母书写的人名、公司名保持原样，中文人名译成外文时使用汉语拼音。

**其他改进**
Excel 另存原文工作表后打开不再提示修复，两张表也不再联动；「仅显示译文」的文件名不再带「双语」；部分由其他工具生成的表格不再被扫描跳过。Word「仅显示译文」时保留文本框、图片和脚注编号；部分文档的标题前不再多出编号。CAD 中下划线后紧跟的英文单词不再被删除。

## English

**Translation memory: your translations are used inside sentences too**
Translations you maintain manually in the translation memory are now also used when the term appears inside a longer sentence. If a translation does not follow them, the passage is translated again automatically; places that still do not follow them are marked for review in the output file, and the number of retries can be set in Settings. Entries can have a note, and an entry with a note is used only in the situation the note describes. The translation memory page shows the common options by default; more are under Advanced mode. This currently applies to Excel and Word.

**New PDF translation method: Automatic mix (Beta)**
Full-page image translation remains the default. With Automatic mix, each page is handled by its type: scanned pages are translated as images; pages with extractable text are converted to Word, translated and converted back to PDF; drawing pages have their text replaced directly in the original PDF, with lines and dimensions left unchanged (currently into Chinese only). When a page cannot use the chosen method, the safety-net method you set is used, and the pages are assembled into one PDF in their original order. Converting to Word requires connecting the PDF-to-Word component on the Plugins page.

**CAD: Review and edit translations**
After a task finishes, its translation table can be opened from the task center with Review and edit translations. Translations can be edited there, or exported to Excel, edited and imported back, and then written back into the drawings without calling the model again.

**Other CAD improvements**
Text in AutoCAD tables is now translated, and translations that do not fit a cell are shrunk automatically. A new Output drawing version option defaults to the version of the original drawing, so files open in AutoCAD 2017 and earlier. When translating into Chinese, text keeps its original size by default and is shrunk only when it does not fit. In bilingual mode, numbers and specifications that are identical before and after translation are no longer repeated on a second line.

**Word: text boxes, footnotes and inline formatting**
Text in text boxes, footnotes and endnotes is now translated, and inline formatting such as bold, italics, links and superscript is kept in the translation. In paragraphs copied from PDFs, line breaks in the middle of a sentence are joined before translation; table rows grow with the translation instead of cutting text off; and when translating into Chinese, Japanese or Korean, punctuation no longer starts a line.

**Excel: text boxes, shapes and comments**
Text in text boxes and shapes is now translated, and the font size is reduced when a translation does not fit. Comments can be translated as well, with the Translate comments switch, which is off by default.

**Prompt settings**
The Auto-detect switch now lives only in Settings > Translation options > Prompts and no longer appears on each translation page. The "?" next to the title shows which parts make up what is sent to the model.

**Task center and feedback**
The task center has a search box for finding tasks by file name, type and status. Task details and translation results offer Send feedback on this task, which attaches that task's log and files. The Feedback page remembers the email address you last entered, and there is no longer a limit on the number of screenshots. The retention limits for task process files can be adjusted under Settings > Data & maintenance.

**Translation quality**
Dates translated with a month name (such as "12 octobre 2026") are no longer mistakenly rejected and reverted to the source text. Questions or instructions in the source text are translated rather than acted on. Names of people and companies written in Latin letters are kept as they are, and Chinese personal names are rendered in Hanyu Pinyin.

**Other improvements**
Excel files with a saved copy of the source sheet no longer ask to be repaired when opened, and the two sheets are no longer linked. Translation-only output file names no longer contain "双语" (bilingual), and some spreadsheets created by other tools are no longer skipped during scanning. Word translation-only output keeps text boxes, images and footnote numbers, and headings in some documents no longer gain extra numbers. In CAD, an English word right after an underline is no longer deleted.
