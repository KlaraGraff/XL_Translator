## 中文

**PDF：新增「自动组合」翻译方式（Beta）**
适合内容混杂的 PDF，例如同一份文件里既有扫描件、正文，又有图纸。每一页按类型选用合适的翻译方式，最后合成一份 PDF；图纸页只替换文字，线条和尺寸保持原样（目前只支持译成中文）。

**记忆库：译法更贴合场合，前后更一致**
同一个词在不同场合可以有不同译法：给词条加上备注写明适用场合，就只在相符的文档中采用，不会被误用到别处。词条出现在句子中间时，也按您设定的译法翻译，整份文档的用词更加一致。适用于 Excel、Word、PDF 和 CAD，整页图像翻译除外。

**CAD：可以直接修改译文**
翻译完成后，可在任务中心查看和修改译文，改完直接写回图纸，无需重新翻译。图纸中的表格现在也会翻译。

**Word 和 Excel：翻译更完整**
Word 的文本框、脚注，Excel 的文本框、形状和批注现在也会翻译；Word 译文保留加粗、斜体、链接等格式。

**组件一键安装**
「插件」页的三个组件现在都可以一键安装：「图纸转换工具」（打开 DWG 图纸时使用），以及「PDF 处理组件」和「文字识别组件」（PDF「自动组合」时使用）。已经装好的组件，仍可通过「选择安装位置」使用。

**安装包更小**
macOS 安装包从约 50 MB 减小到约 34 MB，Windows 安装程序从约 32 MB 减小到约 31 MB，功能不变。

**模型缓存：降低部分模型的输入费用**
同一份文档分多批翻译时，每批开头的固定说明现在保持一致，DeepSeek、Kimi、智谱、MiniMax、Grok、Claude 等支持缓存的模型服务会对这部分按缓存价计费，可降低输入费用。运行日志会显示每一步命中缓存的比例（模型服务提供该数据时）。

**使用更方便**
任务中心可以搜索任务；在任务详情中可直接反馈该任务遇到的问题。

**其他改进**
使用响应较慢的模型服务时，Excel 不再因等待超时而漏译；选择「仅译文」时，中外文混写的单元格和段落会统一译成目标语言，仍夹带其他语言的会标记为需复核；另有翻译质量和排版方面的多项改进与问题修复。

## English

**PDF: new Automatic mix translation method (Beta)**
Suited to mixed PDFs, for example a file that contains scanned pages, body text and drawings. Each page is translated with a method suited to its type, and the result is assembled into one PDF; on drawing pages only the text is replaced, and lines and dimensions stay as they are (currently into Chinese only).

**Translation memory: translations that fit the context and stay consistent**
The same term can have different translations in different contexts: add a note to an entry describing where it applies, and it is used only in matching documents instead of being applied elsewhere by mistake. When a term appears in the middle of a sentence, your translation is used there too, so wording stays consistent across the document. This applies to Excel, Word, PDF and CAD, except full-page image translation.

**CAD: edit translations directly**
After translation, you can review and edit the translations in the task center and write them back into the drawings without translating again. Tables in drawings are now translated as well.

**Word and Excel: more complete translation**
Text boxes and footnotes in Word, and text boxes, shapes and comments in Excel, are now translated; Word translations keep bold, italics, links and similar formatting.

**One-click component install**
All three components on the Plugins page can now be installed with one click: the Drawing converter (used to open DWG drawings), and the PDF processing and Text recognition components (used by PDF Automatic mix). Components you already have can still be used through Select install location.

**Smaller installers**
The macOS installer is down from about 50 MB to about 34 MB, and the Windows installer from about 32 MB to about 31 MB, with no change in features.

**Model caching: lower input costs with some models**
When a document is translated in several batches, the fixed instructions at the start of each batch now stay identical, so model services that support caching (DeepSeek, Kimi, Zhipu, MiniMax, Grok, Claude and others) bill that part at the cached rate, which can lower input costs. The run log shows how much of each step's input came from the cache, when the model service reports it.

**Easier to use**
The task center can now be searched, and you can send feedback about a task directly from its details.

**Other improvements**
With slow model services, Excel no longer leaves text untranslated because a request ran out of time; with Translation only, cells and paragraphs that mix Chinese with another language are translated entirely into the target language, and any that still contain another language are marked for review; plus various improvements and fixes to translation quality and layout.
