# 设备监控服务部署说明

本文说明如何在一台新的服务器上部署设备监控服务，
并完成首次配置。部署前请确认服务器可以访问内网镜像源。

## 一、准备工作

1. 准备一台 Linux 服务器（建议 4 核 8 GB 内存）。
2. 安装 Docker 20.10 或更高版本，执行 `docker --version` 确认。
3. 申请数据库账号：
   - 读写账号用于写入采集数据；
   - 只读账号用于报表查询。
4. 下载安装包，地址见 [发布页面](https://example.com/releases "发布页面")。

- [x] 已开通防火墙 8080 端口
- [ ] 已配置时间同步

> **注意：** 生产环境不要使用默认密码。
> 修改方法见下文「安全设置」一节。

## 二、安装步骤

解压安装包后，在安装目录下执行：

```bash
tar -xzf monitor-2.3.tar.gz
cd monitor && ./install.sh --port 8080
```

安装脚本会自动创建 `monitor` 用户。若需要指定数据目录，请修改 `config.yaml` 中的 `data_dir` 项。  
修改后重启服务即可生效。

    # 旧版本的手动启动方式（仅供参考）
    systemctl start monitor

安装完成
--------

服务启动后，浏览器打开 <http://localhost:8080> 即可看到登录页。也可以访问 https://example.com/docs 查看完整文档[^1]。

## 三、端口说明

| 端口 | 用途 | 是否必须 |
|:-----|:----:|-----:|
| 8080 | 网页界面 | 是 |
| 9100 | 指标采集（`/metrics`） | 否 |
| 5432 | 数据库 \| 内部访问 | 是 |
